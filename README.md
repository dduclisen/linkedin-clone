# Trabahe

A responsive, static professional-networking app prototype.

## Pages

- `index.html` — feed
- `network.html` — connection suggestions
- `jobs.html` — job search and saved roles
- `messaging.html` — sample conversations
- `notifications.html` — network activity
- `profile.html` — profile and work history
- `login.html` and `signup.html` — demo authentication flows

Open `index.html` in a browser (or serve this folder with any static file server). Demo sign-in accepts any valid email and a password of at least six characters. Sign-up stores only the demo name and email in browser local storage; no authentication service or backend is connected.
